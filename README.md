## Assignment A1
The problem we encountered based on the 26-06 Client report, pages 16 to 18. 

### Identified issues
In the original report we noticed the current foundation utilization percentage for two of the points are above 90 %, and one of them is at 99% (point foundation type F) which means it can't bear any more load. The proposal is to demolish the auditoriums, and add an additional three floor structure, thus increasing the general load. The new building is supposed to be carried by the foundation type D (with an utilization of a 56%), however, they're inmediately next to the foundation type F, so they should be checked.

### Possible solutions
Redistribute load to adjecent fondation points, reinforce type F point foundations.
